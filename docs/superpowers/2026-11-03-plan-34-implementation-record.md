## Task 8: Passwordless connections

- `internal/connrules/passwordless.go`: `email` and `sms` strategies accepted by `normalize`/`CreateDefaults`. Options are validated against the frozen phonerules JSON schema (compiled once, cached) with the contract defaults merged in (also stored on create, as Auth0 shows them). Name must equal the strategy (P18; one per strategy follows from name uniqueness). Database options and the database-only Extra keys are refused; `non_persistent_attrs`, `disable_signup`, `brute_force_protection` stay. `authParams` accepts a query string or an object of strings. `gateway_url` is checked statically (https, no credentials, no localhost/.local/.internal, no literal private/loopback/link-local IPs); `sms_gateway` requires it. Dial-time checks stay in Task 9.
- Secrets: `twilio_token` and `gateway_authentication.secret` are removed from Extra (`MergePasswordlessSecrets`) and sealed in `ConfigurationSealed` under `twilio_token`/`gateway_secret`; never returned (P17), kept on PATCH when not resent, replaced when sent, cleared by null (gateway secret also cleared with `gateway_authentication: null`). Validation messages never echo credential values.
- `connrules.PasswordlessOf(conn, open)` returns `PasswordlessOptions` (defaults applied, credentials unsealed through the `open` hook). Views hide database options for these strategies.
