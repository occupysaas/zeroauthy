## Plan 25 email-account inventory (2026-10-26)

Implemented (Plan 25); guide: `docs/email-account-connections.md`. Microsoft
personal (`windowslive`) and work/school (`waad`) target public-cloud v2 only.
Google Gmail/Workspace/non-Gmail accounts preserve the predecessor adapter.
Local differences: fixed Microsoft openid/profile/email scopes, no Graph or
profile scripts, false/absent Microsoft email verification, organizations-only
multitenancy, tenant-bound `tid:oid` identifiers, immutable identity bindings,
explicit rejected unsupported security options, and capability/data preflight.
No legacy Live/Graph ID parity or live provider observation is established.
See [email-account evidence](observations/email-account-connections.md) and
D-0051. Verified against local mock providers only: Chromium code+PKCE logins
for nine personas (m25), node-auth0 7.4.0, auth0-cli 1.37.0 and the strict
Deploy CLI 9.1.0 four-cell matrix with post-import logins. No live Microsoft,
Google or Auth0 observation.

Plan 26 implemented and locally verified (2026-10-27): tenant roles,
direct permissions, effective direct-role union, RBAC enforcement and four token
profiles. See [public contract review](observations/roles-permissions.md) and
D-0052. All 16 tenant-role operations, current grant enforcement, console,
SDK/CLI/browser and four-cell Deploy CLI migration pass local verification;
group/organization-role and effective-role APIs remain deferred. See the
[implementation record](../superpowers/2026-10-27-plan-26-implementation-record.md)
for full SQL/race/conformance results and unavailable live evidence.

Plan 29 contracts frozen (2026-10-28), not yet implemented: the Organizations
I inventory has 20 Management operations, the client and tenant
organization fields, limits and the spec §2 items 1–10 with their observation
status. See `internal/orgrules/inventory.json`,
[observation notes](observations/organizations.md) and D-0055. The upstream
routes `/organizations/{id}/connections` (Early Access), invitations, client
